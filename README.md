# 猜数字小游戏

这是一个适合初学者的 Python 命令行程序。电脑随机选择一个 1 到 100 的整数，你输入猜测，程序告诉你“太大了”或“太小了”，直到猜对。

## 运行方法

安装 Python 3，下载仓库，在仓库所在目录打开终端并运行：

```bash
python guess_number.py
```

如果电脑使用 `python3` 命令，则运行 `python3 guess_number.py`。程序只使用 Python 标准库，不需要额外安装依赖。

## 示例

```text
请输入你的猜测：50
太小了，再试一次！
请输入你的猜测：75
太大了，再试一次！
请输入你的猜测：62
猜对了！答案是 62，你一共猜了 3 次。
```

每局答案都随机生成。输入 `q` 可以退出；输入文字或超出范围的数字会收到提示，且不会计入猜测次数。

## 能学到什么

- `random.randint(1, 100)`：随机生成整数。
- `input()` 和 `print()`：接收键盘输入并显示信息。
- 变量：保存答案和猜测次数。
- `while` 循环：重复接收猜测。
- `if / elif / else`：比较猜测和答案。
- `try / except`：处理无法转换成整数的输入。
- `main()`：把游戏逻辑组织成一个函数。

文件最后的 `if __name__ == "__main__":` 表示：直接运行这个文件时启动游戏；被其他 Python 文件导入时不自动启动。
